# My layerkit MCP server

This is a [layerkit](https://github.com/slashbase/layerkit) tool-spec repo.
It contains `*.tool.yaml` specs that compile into an MCP (Model Context
Protocol) server — no code required.

## Prerequisites

The `layerkit` binary must be on your PATH.
```
layerkit --version
```

## Structure

- `hello.tool.yaml` — a working example spec. Copy this pattern to add your
  own tools.
- `.layerkit/` — build artifacts and the tool index, generated by
  `layerkit build`. Do not edit or commit this directory.

## Usage

Build all specs in this directory into compiled artifacts:

```
layerkit build
```

Start the MCP server, exposing every built flow as a tool:

```
layerkit serve
```

Point your MCP client (e.g. Claude Desktop) at this server to call `hello`
and any other tools you add.

## Adding a new tool

Copy `hello.tool.yaml` to `<your-tool>.tool.yaml` and edit:

- `name` / `description` — the flow's identity
- `input` — the flow's top-level input variable names
- `layers` — an ordered list of steps. Each layer names its own `input`
  and `output` variables; a layer's input must match variable names
  produced by an earlier layer (or the flow's top-level `input`).

Run `layerkit build` again to compile it.
